## 📝 Step-by-Step Instructions

### Creating the Test Page

1. **Open Strapi Admin**: http://localhost:1337/admin

2. **Navigate to Content Manager** → **Page** → **Create new entry**

3. **Fill Basic Info**:

   - **Title**: "Features"
   - **Slug**: "features"
   - **Breadcrumb Title**: "Features"

4. **Add Components**:

   - Scroll to **Content** section
   - Click **"Add a component"**
   - Select each component from the picker
   - Fill in the test data above

5. **Save Draft** (Ctrl+S)

6. **Publish** (Click green Publish button)

7. **⚠️ CRITICAL: Recalculate FullPath**

   After publishing a new page, the `fullPath` field won't be populated immediately. You must trigger the recalculation:

   - Navigate to **Content Manager** → **InternalJob**
   - You'll see a pending `RECALCULATE_FULLPATH` job
   - Click the **"Recalculate all fullpaths"** button (top right)
   - Wait for the job to complete (status changes to "completed")
   - Your page's `fullPath` will now be populated (e.g., `/features`)

   **Why?** The system creates background jobs to avoid performance issues during page creation. The fullPath is required for the page to be accessible on the frontend.

   **Reference**: See `apps/strapi/README.md` section "Fullpath generation and redirects" for details.

8. **View Page**: http://localhost:3000/features

- ✅ **Orientation**: Horizontal or Vertical scrolling
- ✅ **Speed Control**: Customizable duration (5-120 seconds)
- ✅ **Interactive**: Pause on hover
- ✅ **Visual Effects**: Gradient fade edges
- ✅ **Responsive**: Works seamlessly on all devices

### Configuration Guide

#### Display Types

| Type          | Best For                     | Shows                              |
| ------------- | ---------------------------- | ---------------------------------- |
| **Logos**     | Partners, Tech Stack, Brands | Company logos with optional links  |
| **Testimon.** | Customer Feedback            | Cards with avatar, quote, rating   |
| **Reviews**   | User Comments, Social Proof  | Compact cards with username, stars |

#### Orientation Options

| Orientation    | Description        | Best Use Case                |
| -------------- | ------------------ | ---------------------------- |
| **Horizontal** | Scrolls left/right | Logo showcases, wide layouts |
| **Vertical**   | Scrolls top/bottom | Sidebar content, tall spaces |

#### Multi-Row Settings

| Setting                 | Values | Effect                                          |
| ----------------------- | ------ | ----------------------------------------------- |
| **Rows**                | 1-5    | Number of simultaneous marquee rows             |
| **Alternate Direction** | Yes/No | Odd rows go one way, even rows go opposite      |
| **Vary Speed**          | Yes/No | Each row has slightly different speed for flair |

#### Speed & Spacing

| Setting      | Range       | Recommended | Notes               |
| ------------ | ----------- | ----------- | ------------------- |
| **Duration** | 5-120s      | 30-50s      | Lower = faster      |
| **Gap**      | Any CSS rem | 1.5-2.5rem  | Space between items |

### Best Practices

#### ✅ DO

- **Use 8-12 items minimum** for smooth seamless looping
- **Keep content concise** in testimonials/reviews (2-3 sentences max)
- **Use high-quality images** for logos and avatars
- **Test multi-row** configurations with odd/even item counts
- **Enable pauseOnHover** for better user experience
- **Use showFade** for polished edges

#### ❌ DON'T

- Don't use less than 6 items (may look sparse)
- Don't make testimonials too long (slows reading)
- Don't use wildly different image sizes
- Don't set duration too low (<15s) - causes dizziness
- Don't disable pauseOnHover on testimonials (users can't read)

### Troubleshooting

**Problem**: Marquee resets/jumps  
**Solution**: Ensure you have at least 8-12 items for seamless loop

**Problem**: Too fast/slow  
**Solution**: Adjust duration (30-50s is sweet spot)

**Problem**: Items not aligned  
**Solution**: Use consistent image aspect ratios

**Problem**: Fade not showing  
**Solution**: Ensure showFade is enabled
