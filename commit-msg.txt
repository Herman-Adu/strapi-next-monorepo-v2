### 2. Responsive Alignment Architecture

**Problem:** Strapi stores static alignment (center|left|right). No way to specify
responsive alignment patterns (center mobile → left desktop).

**Solution: Hybrid Approach**
- Parent containers control layout via flex/grid
  (`items-center lg:items-start`)
- className prop can override Strapi alignment with responsive classes
- SectionHeader detects responsive overrides via regex pattern matching
- Divider alignment follows text alignment (static or responsive)

**Pattern Established:**

```tsx
// Parent controls layout
<div className="flex items-center lg:items-start">
  
  // Child overrides Strapi alignment
  <SectionHeader 
    header={component.header}
    className="text-center lg:text-left"
  />
</div>
```

**Implementation:**
- `SectionHeader.tsx`: Added `hasResponsiveAlignment` regex detection
- `SectionHeader.tsx`: Added `effectiveAlignmentClass` conditional logic
- `SectionHeader.tsx`: Divider uses `mx-auto lg:mr-auto lg:ml-0` when
  responsive detected
- Applied to both two-tone and default rendering paths

### 3. Form Height Matching & Dynamic Growth

**TwoColumnLayout Enhancement:**
- Added `matchHeights?: boolean` prop
- Applies `lg:grid-rows-1 lg:items-stretch` when true
- Forces equal column heights on desktop (requires child h-full)

**ContactFormCard Responsive Alignment:**
- Added `flex h-full flex-col` for height filling
- Added `items-center lg:items-start` for responsive centering
- Form centers on mobile, left-aligns on desktop

**Dynamic Textarea Growth:**
- `ContactForm.tsx`: Changed `space-y-4` → `flex h-full flex-col gap-4`
- `AppForm.tsx`: Changed `space-y-5` → `flex flex-col gap-5`
- `AppTextArea.tsx`: Added JSDoc for `containerClassName="flex-1"` pattern
- `Textarea.tsx`: Added container query-based min/max heights:
  - Min heights: `min-h-32 @sm:min-h-36 @md:min-h-40 @lg:min-h-48`
  - Max heights: `max-h-64 @md:max-h-80 @lg:max-h-96 @xl:max-h-[600px]`

### 4. Null-Safety Improvements

**ContactMethod.tsx:**
- Added conditional rendering: `{icon && icon.iconType && (...)}`
- Added null coalescing: `icon.lucideName ?? undefined`
- Prevents TypeScript errors when Strapi returns null values

## 🎨 Architectural Patterns Established

### 1. Responsive Alignment Override Pattern
**Generic components stay layout-agnostic. Parents control via className
overrides.**

```tsx
<SectionHeader 
  header={strapiData}
  className="text-center lg:text-left"
/>
```

### 2. Container Query Pattern
**Component-level responsiveness independent of viewport breakpoints.**
```tsx
<textarea className="min-h-32 @sm:min-h-36 @md:min-h-40 @lg:min-h-48" />
```

### 3. Parent Container Control
**Parents control layout. Children inherit via flex/grid.**

```tsx
<div className="flex items-center lg:items-start">
  <ChildComponent />
</div>
```

### 4. Null-Safety for Strapi Data
**Always guard against Strapi null/undefined values.**

```tsx
{icon && icon.iconType && (
  <Icon
    iconType={icon.iconType}
    lucideName={icon.lucideName ?? undefined}
  />
)}
```

## 🔄 Migration Guide

### For Icon Usage

**Before:**
```tsx
<div>
  {icon && <LucideIcon name={icon} />}
  {customIcon && <img src={customIcon} />}
</div>
```

**After:**
```tsx
<Icon 
  iconType={icon.iconType}
  lucideName={icon.lucideName ?? undefined}
  emoji={icon.emoji ?? undefined}
  customImage={icon.customImage ?? undefined}
  size="md"
/>
```

### For Responsive Alignment

**Before:**

```tsx
<SectionHeader header={component.header} />
```

**After:**

```tsx
<SectionHeader 
  header={component.header}
  className="text-center lg:text-left"
/>
```
