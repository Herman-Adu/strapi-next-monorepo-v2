## 250 Lines of Code → One Line

I was building a documentation system. The user asked:

> "Is there a convenient way to style the MDX? Maybe a Tailwind plugin to give elements their proper size, like h1, h2, etc?"

My first instinct: manually style every HTML element that markdown generates.

```tsx
<div className="max-w-none">
  <Markdown
    options={{
      overrides: {
        h1: {
          component: ({ children }) => (
            <h1 className="text-5xl font-bold tracking-tight mb-6">
              {children}
            </h1>
          ),
        },
        h2: {
          component: ({ children }) => (
            <h2 className="text-4xl font-semibold mb-4">{children}</h2>
          ),
        },
        h3: {
          component: ({ children }) => (
            <h3 className="text-3xl font-medium mb-3">{children}</h3>
          ),
        },
        p: {
          component: ({ children }) => (
            <p className="mb-4 leading-7 text-foreground">{children}</p>
          ),
        },
        ul: {
          component: ({ children }) => (
            <ul className="list-disc pl-6 mb-4 space-y-2">{children}</ul>
          ),
        },
        ol: {
          component: ({ children }) => (
            <ol className="list-decimal pl-6 mb-4 space-y-2">{children}</ol>
          ),
        },
        li: {
          component: ({ children }) => (
            <li className="leading-7">{children}</li>
          ),
        },
        // ... 15+ more element overrides
      },
    }}
  >
    {content}
  </Markdown>
</div>
```

**Total:** ~250 lines of overrides

Then I discovered the Typography plugin.

**New version:**

```tsx
<article className="prose prose-lg dark:prose-invert max-w-none">
  <Markdown>{content}</Markdown>
</article>
```

**Total:** 1 line

**Code reduction:** 250 lines → 1 line (250x less code)

## What Is the Typography Plugin?

The **@tailwindcss/typography** plugin adds beautiful default styles for markdown/HTML content.

**Key features:**

- ✅ Professional typography designed by experts
- ✅ All HTML elements styled automatically
- ✅ Dark mode support built-in
- ✅ Responsive sizing modifiers
- ✅ Zero configuration needed
- ✅ Customizable with element modifiers

**The magic class:** `prose`

---

## Installation (Tailwind v4)

### Step 1: Add Plugin to globals.css

```css
/* apps/ui/src/styles/globals.css */
@import "tailwindcss";
@import "@repo/design-system/theme.css";
@import "@repo/design-system/custom-styles.css";

@plugin "tailwindcss-animate";
@plugin "@tailwindcss/typography"; /* ← Add this */
```

**Note:** In Tailwind v4, typography plugin is bundled! No npm install needed.

**For Tailwind v3:**

```bash
npm install -D @tailwindcss/typography
```

```javascript
// tailwind.config.js
module.exports = {
  plugins: [require("@tailwindcss/typography")],
}
```

### Step 2: Use in Component

```tsx
<article className="prose">
  <h1>Your Heading</h1>
  <p>Your content here...</p>
</article>
```

That's it. Everything inside `prose` is now beautifully styled.

### Available Sizes

```tsx
{
  /* Small (14px base) */
}
;<article className="prose-sm">...</article>

{
  /* Base (16px) - default */
}
;<article className="prose">...</article>

{
  /* Large (18px base) */
}
;<article className="prose-lg">...</article>

{
  /* Extra Large (20px base) */
}
;<article className="prose-xl">...</article>

{
  /* 2X Large (24px base) */
}
;<article className="prose-2xl">...</article>
```

**Size comparison:**

| Modifier  | Base Font | H1 Size | H2 Size  | Use Case                     |
| --------- | --------- | ------- | -------- | ---------------------------- |
| prose-sm  | 14px      | 2rem    | 1.5rem   | Sidebars, dense content      |
| prose     | 16px      | 2.25rem | 1.875rem | Standard body text           |
| prose-lg  | 18px      | 2.5rem  | 2rem     | Blog posts, articles         |
| prose-xl  | 20px      | 3rem    | 2.25rem  | Landing pages, marketing     |
| prose-2xl | 24px      | 3.5rem  | 2.75rem  | Hero sections, large screens |

**Example usage:**

```tsx
<article className="prose lg:prose-lg xl:prose-xl">
  {/* Mobile: base size (16px) */}
  {/* Desktop: large (18px) */}
  {/* Wide screens: extra large (20px) */}
</article>
```

## Dark Mode Support

### Automatic Dark Mode

```tsx
<article className="prose dark:prose-invert">
  {/* Light mode: dark text on light background */}
  {/* Dark mode: light text on dark background */}
</article>
```

**What `prose-invert` does:**

- Inverts colors automatically
- Light text on dark background
- Maintains proper contrast ratios
- Styled for readability in dark mode

**Example with size:**

```tsx
<article className="prose prose-lg dark:prose-invert">
  {/* Large typography + dark mode support */}
</article>
```

## Customizing with Element Modifiers

### Override Specific Elements

```tsx
<article
  className="prose 
  prose-h1:text-5xl 
  prose-h1:font-black 
  prose-h2:text-brand-primary 
  prose-p:text-gray-700 
  prose-a:text-blue-600 
  prose-a:no-underline
  prose-code:text-pink-600
  prose-code:before:content-none
  prose-code:after:content-none
  dark:prose-invert"
>
  <Markdown>{content}</Markdown>
</article>
```

**Available element modifiers:**

- `prose-h1:*` - Target h1 elements
- `prose-h2:*` - Target h2 elements
- `prose-p:*` - Target paragraphs
- `prose-a:*` - Target links
- `prose-strong:*` - Target bold text
- `prose-code:*` - Target inline code
- `prose-pre:*` - Target code blocks
- `prose-ul:*` - Target unordered lists
- `prose-ol:*` - Target ordered lists
- `prose-li:*` - Target list items
- `prose-blockquote:*` - Target quotes
- `prose-img:*` - Target images
- `prose-video:*` - Target videos
- `prose-table:*` - Target tables
- `prose-thead:*` - Target table headers
- `prose-tr:*` - Target table rows
- `prose-td:*` - Target table cells

**Real-world example:**

```tsx
<article
  className="
  prose prose-lg
  prose-headings:font-semibold
  prose-h1:text-4xl prose-h1:text-primary
  prose-h2:text-3xl prose-h2:border-b prose-h2:pb-2
  prose-p:text-muted-foreground
  prose-a:text-blue-600 prose-a:underline-offset-4
  prose-code:text-sm prose-code:bg-muted prose-code:px-1 prose-code:py-0.5 prose-code:rounded
  prose-img:rounded-lg prose-img:shadow-md
  dark:prose-invert
  max-w-none
"
>
  <Markdown>{content}</Markdown>
</article>
```

## Removing Default Max-Width

**By default,** prose has `max-width: 65ch` (optimal reading width).

**To make full-width:**

```tsx
<article className="prose max-w-none">{/* Full width content */}</article>
```

**Why 65ch default?**

- Optimal line length for readability
- ~65-75 characters per line
- Based on typography research

**When to use `max-w-none`:**

- Full-width documentation
- Wide layouts
- Custom container sizing

## Real Component Example

### Documentation Page Component

```tsx
// components/docs/MarkdownRenderer.tsx
import Markdown from "react-markdown"

interface MarkdownRendererProps {
  content: string
}

export function MarkdownRenderer({ content }: MarkdownRendererProps) {
  return (
    <article className="prose prose-lg dark:prose-invert max-w-none prose-headings:scroll-mt-20 prose-h1:text-4xl prose-h1:font-bold prose-h2:text-3xl prose-h2:border-b prose-h2:pb-2 prose-h2:border-border prose-pre:bg-muted prose-code:text-sm">
      <Markdown>{content}</Markdown>
    </article>
  )
}
```

**What this does:**

- ✅ Large typography (`prose-lg`)
- ✅ Dark mode support (`dark:prose-invert`)
- ✅ Full width (`max-w-none`)
- ✅ Scroll margin for anchor links (`scroll-mt-20`)
- ✅ Custom h1 sizing (`text-4xl`)
- ✅ H2 bottom border (`border-b pb-2`)
- ✅ Custom code block background (`bg-muted`)

## Common Pitfalls

### ❌ Forgetting `max-w-none`

```tsx
<article className="prose">{/* Oops! Content constrained to 65ch */}</article>
```

**Fix:**

```tsx
<article className="prose max-w-none">{/* Full width ✓ */}</article>
```

### ❌ Not Adding Dark Mode

```tsx
<article className="prose">
  {/* Dark mode: black text on black background (unreadable) */}
</article>
```

**Fix:**

```tsx
<article className="prose dark:prose-invert">
  {/* Dark mode: light text ✓ */}
</article>
```

### ❌ Wrapping in Wrong Element

```tsx
<div className="prose">{/* Semantic HTML matters */}</div>
```

**Better:**

```tsx
<article className="prose">{/* Proper semantic element ✓ */}</article>
```

### ❌ Fighting the Defaults

```tsx
<article className="prose prose-h1:text-base prose-p:leading-none">
  {/* Why use prose if you override everything? */}
</article>
```

**Better:** Either embrace the defaults or use manual styling.

## When to Use Prose vs Manual Styling

### ✅ Use Prose When:

- Rendering markdown/HTML content
- Building documentation sites
- Styling blog posts
- Creating CMS-driven pages
- You want professional defaults

### ❌ Don't Use Prose When:

- Building custom layouts (hero sections, landing pages)
- Need precise pixel-perfect control
- Designing unique UI components
- Overriding >50% of defaults (defeats the purpose)
