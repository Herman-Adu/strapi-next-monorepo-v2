## Overview

### What You'll Build

Professional markdown styling using Tailwind's Typography plugin. Replace 250+ lines of manual CSS with a single `prose` className, achieving publication-quality typography with zero maintenance.

- 250+ lines of component overrides for headings, lists, code blocks, tables
- 5+ hours initial implementation time
- ~2 hours/quarter for typography updates
- Inconsistent results across different content types
- No dark mode support without doubling CSS

- ✅ Install and configure @tailwindcss/typography plugin

## Step 3: Apply prose Class

### Basic Implementation

```tsx
// ✅ Typography plugin - 1 line!
// components/MarkdownContent.tsx

import Markdown from "markdown-to-jsx"

interface MarkdownContentProps {
  content: string
}

export function MarkdownContent({ content }: MarkdownContentProps) {
  return (
    <article className="prose dark:prose-invert max-w-none">
      <Markdown>{content}</Markdown>
    </article>
  )
}

// Result: 1 line does it all!
```

## Step 4: Size Modifiers

### Available Sizes

```tsx
// prose-sm → 14px base (compact)
<article className="prose prose-sm">
  {content}
</article>

// prose (default) → 16px base
<article className="prose">
  {content}
</article>

// prose-lg → 18px base (comfortable) ⭐ RECOMMENDED
<article className="prose prose-lg">
  {content}
</article>

// prose-xl → 20px base (reading)
<article className="prose prose-xl">
  {content}
</article>

// prose-2xl → 24px base (hero content)
<article className="prose prose-2xl">
  {content}
</article>
```

### Responsive Sizing

```tsx
// Mobile: default size, Desktop: large size
<article className="prose md:prose-lg lg:prose-xl">
  {content}
</article>

// Mobile: small, Tablet: default, Desktop: large
<article className="prose prose-sm md:prose-base lg:prose-lg">
  {content}
</article>
```

### When to Use Each Size

| Size           | Use Case                            | Example                           |
| -------------- | ----------------------------------- | --------------------------------- |
| `prose-sm`     | Sidebar content, comments, captions | User comments, footnotes          |
| `prose` (base) | Standard content, forms             | Contact forms, short descriptions |
| `prose-lg`     | Blog posts, documentation           | **Most common choice**            |
| `prose-xl`     | Long-form articles, reading content | In-depth guides, whitepapers      |
| `prose-2xl`    | Hero sections, landing pages        | Above-the-fold content            |

## Step 5: Dark Mode Support

### Basic Dark Mode

```tsx
// Automatic color inversion for dark backgrounds
<article className="prose dark:prose-invert">{content}</article>
```

**What `prose-invert` does:**

- ✅ White text on dark backgrounds
- ✅ Adjusted link colors for readability
- ✅ Proper contrast for code blocks
- ✅ Inverted blockquote borders
- ✅ Table border colors adjusted

### Color Variants (Light Mode)

```tsx
// Gray text (default)

  {content}
</article>

// Slate text (cooler tone)

  {content}
</article>

// Neutral text
<article className="prose prose-neutral">
  {content}
</article>

// Stone text (warmer tone)

  {content}
</article>
```

## Step 6: Width Control

### Default Width

```tsx
// prose has max-w-65ch (readable line length)
<article className="prose">{content}</article>
```

**Result:** Content limited to ~65 characters per line for readability.

### Remove Width Constraint

```tsx
// Full width content
<article className="prose max-w-none">{content}</article>
```

**Use when:** Content inside a container that already controls width.

### Custom Width

```tsx
// Custom max-width
<article className="prose max-w-4xl mx-auto">
  {content}
</article>

// Percentage-based width
<article className="prose w-full md:w-3/4 lg:w-2/3">
  {content}
</article>
```

## Step 8: Exclude Content from prose

### The Problem

```tsx
// Problem: Everything inside prose gets styled
<article className="prose">
  <Markdown>{content}</Markdown>

  {/* This custom component gets prose styles (may break layout) */}
  <MyCustomStyledComponent />
</article>
```

### The Solution: `not-prose`

```tsx
// Solution: Use not-prose to exclude elements
<article className="prose dark:prose-invert max-w-none">
  <Markdown>{content}</Markdown>

  {/* This component keeps its own styling */}
  <div className="not-prose">
    <MyCustomStyledComponent />
  </div>

  {/* More markdown content */}
  <Markdown>{moreContent}</Markdown>
</article>
```

### Real-World Example

```tsx
// app/blog/[slug]/page.tsx
export default async function BlogPost({
  params,
}: {
  params: { slug: string }
}) {
  const post = await getPostBySlug(params.slug)

  return (
    <div className="container mx-auto px-4 py-16">
      {/* Header - NOT prose styled */}
      <header className="mb-12 text-center">
        <h1 className="text-5xl font-bold mb-4">{post.title}</h1>
        <p className="text-gray-600 dark:text-gray-400">
          {post.date} · {post.readingTime} min read
        </p>
      </header>

      {/* Content - prose styled */}
      <article className="prose prose-lg dark:prose-invert max-w-none">
        <Markdown>{post.content}</Markdown>
      </article>

      {/* Related posts - NOT prose styled */}
      <aside className="not-prose mt-16">
        <h2 className="text-2xl font-bold mb-6">Related Posts</h2>
        <RelatedPostsGrid posts={post.related} />
      </aside>
    </div>
  )
}
```

## Step 10: Real-World Implementation

### Blog Post Component

```tsx
// components/BlogPostContent.tsx
import Markdown from "markdown-to-jsx"

interface BlogPostContentProps {
  content: string
  size?: "sm" | "base" | "lg" | "xl" | "2xl"
}

export function BlogPostContent({
  content,
  size = "lg",
}: BlogPostContentProps) {
  const sizeClass = size === "base" ? "prose" : `prose prose-${size}`

  return (
    <article
      className={`
      ${sizeClass}
      dark:prose-invert 
      max-w-none
      prose-headings:scroll-mt-16
      prose-a:text-blue-600
      prose-a:font-medium
      hover:prose-a:underline
      prose-code:text-pink-600
      prose-pre:bg-gray-900
      prose-img:rounded-xl
      prose-img:shadow-lg
    `}
    >
      <Markdown>{content}</Markdown>
    </article>
  )
}
```

**Usage:**

```tsx
<BlogPostContent content={post.content} size="lg" />
```

## Common Pitfalls & Solutions

### Issue 1: Content Too Narrow

**Problem:**

```tsx
<article className="prose">{/* Content limited to 65ch max-width */}</article>
```

**Solution:**

```tsx
<article className="prose max-w-none">{/* Full width content */}</article>
```

---

### Issue 2: Dark Mode Unreadable

**Problem:**

```tsx
<div className="bg-gray-900">
  <article className="prose">{/* Gray text on dark bg = unreadable */}</article>
</div>
```

**Solution:**

```tsx
<div className="bg-gray-900">
  <article className="prose dark:prose-invert">
    {/* White text on dark bg = readable */}
  </article>
</div>
```

---

### Issue 3: Custom Components Break

**Problem:**

```tsx
<article className="prose">
  <Markdown>{content}</Markdown>
  <MyCustomButton /> {/* Gets prose styles, layout breaks */}
</article>
```

**Solution:**

```tsx
<article className="prose">
  <Markdown>{content}</Markdown>
  <div className="not-prose">
    <MyCustomButton /> {/* Keeps own styles */}
  </div>
</article>
```

---
