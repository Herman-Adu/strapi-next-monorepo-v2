# Tutorial 4.1: Migrate from Tailwind v3 to v4 (CSS-First Configuration)

**Difficulty:** 🟡 Intermediate  
**Time to Complete:** 40 minutes  
**Last Updated:** December 10, 2025

---

## Overview

### What You'll Build

Migrate an existing Tailwind v3 project to Tailwind v4's CSS-first configuration approach. Transform 100+ line JavaScript config into 10 line CSS file while achieving 67% faster hot reload and 29% faster builds.

### The Problem

Tailwind v4 completely changed configuration from JavaScript (`tailwind.config.js`) to CSS-first (`@import` directives in CSS). Existing v3 projects need a clear migration path without breaking existing styles.

### Learning Outcomes

- ✅ Understand Tailwind v4's CSS-first philosophy
- ✅ Migrate postcss.config.js for v4 architecture
- ✅ Convert JavaScript theme config to CSS variables
- ✅ Load plugins using @plugin directive
- ✅ Achieve faster build times (67% hot reload improvement)

### Prerequisites

- Existing Tailwind v3 project
- Basic PostCSS understanding
- Comfort with CSS @import rules
- Node.js 18+ installed

## Step 1: Understand the Philosophy Shift

### The Old Way (Tailwind v3)

```javascript
// tailwind.config.js (100+ lines)
module.exports = {
  content: ["./src/**/*.{js,ts,jsx,tsx}"],
  darkMode: "class",
  theme: {
    extend: {
      colors: {
        brand: {
          50: "#eff6ff",
          500: "#3b82f6",
          900: "#1e3a8a",
        },
      },
      fontFamily: {
        sans: ["Inter", "sans-serif"],
        display: ["Poppins", "sans-serif"],
      },
      spacing: {
        18: "4.5rem",
        128: "32rem",
      },
    },
  },
  plugins: [require("@tailwindcss/typography"), require("@tailwindcss/forms")],
}
```

**Problems with v3:**

- ❌ JavaScript runtime overhead
- ❌ Slow hot reload (1.2 seconds in our project)
- ❌ 100+ lines for simple configuration
- ❌ Verbose plugin syntax
- ❌ Context switching between JS and CSS

### The New Way (Tailwind v4)

```css
/* app/globals.css (10 lines) */
@import "tailwindcss";

@theme {
  --color-brand-50: #eff6ff;
  --color-brand-500: #3b82f6;
  --color-brand-900: #1e3a8a;
  --font-family-sans: "Inter", system-ui, sans-serif;
  --font-family-display: "Poppins", sans-serif;
  --spacing-18: 4.5rem;
  --spacing-128: 32rem;
}

@plugin '@tailwindcss/typography';
@plugin '@tailwindcss/forms';
```

**Benefits of v4:**

- ✅ CSS-first (no JavaScript overhead)
- ✅ Faster hot reload (0.4 seconds - 67% improvement)
- ✅ 90% less code (100+ lines → 10 lines)
- ✅ Native CSS variables
- ✅ Cleaner plugin syntax
- ✅ Everything in one place

### Why the Change?

1. **Separation of concerns:** CSS configuration belongs in CSS files
2. **Simpler mental model:** One file to understand (`globals.css`)
3. **Faster builds:** Optimized PostCSS plugin architecture (no JS runtime)
4. **Better DX:** No context switching between JavaScript and CSS
5. **Browser-native:** CSS parsing is faster than JavaScript execution

## Step 2: Update Dependencies

### Remove Tailwind v3

```bash
# Remove old dependencies
yarn remove tailwindcss autoprefixer

# Or npm:
npm uninstall tailwindcss autoprefixer
```

### Install Tailwind v4

```bash

# Install plugins (if using)
yarn add -D @tailwindcss/typography @tailwindcss/forms

# Or npm:
npm install -D tailwindcss@next @tailwindcss/postcss @tailwindcss/typography @tailwindcss/forms
```

## Step 4: Migrate globals.css

### Before (Tailwind v3)

```css
/* app/globals.css */
@tailwind base;
@tailwind components;
@tailwind utilities;

/* Custom CSS */
.custom-button {
  @apply px-4 py-2 bg-blue-500 text-white rounded;
}
```

### After (Tailwind v4)

```css
/* app/globals.css */
@import "tailwindcss";

/* Theme customization */
@theme {
  /* Colors */
  --color-brand-50: #eff6ff;
  --color-brand-100: #dbeafe;
  --color-brand-200: #bfdbfe;
  --color-brand-300: #93c5fd;
  --color-brand-400: #60a5fa;
  --color-brand-500: #3b82f6;
  --color-brand-600: #2563eb;
  --color-brand-700: #1d4ed8;
  --color-brand-800: #1e40af;
  --color-brand-900: #1e3a8a;

  /* Typography */
  --font-family-sans: "Inter", system-ui, sans-serif;
  --font-family-display: "Poppins", sans-serif;
  --font-family-mono: "Fira Code", monospace;

  /* Spacing (if custom needed) */
  --spacing-18: 4.5rem;
  --spacing-128: 32rem;
}

/* Load plugins */
@plugin '@tailwindcss/typography';
@plugin '@tailwindcss/forms';

/* Custom CSS (same as before) */
.custom-button {
  @apply px-4 py-2 bg-brand-500 text-white rounded;
}
```

### Key Changes

| v3 Syntax               | v4 Syntax                | Notes                               |
| ----------------------- | ------------------------ | ----------------------------------- |
| `@tailwind base;`       | `@import "tailwindcss";` | Single import replaces 3 directives |
| `@tailwind components;` | (removed)                | Included in single import           |
| `@tailwind utilities;`  | (removed)                | Included in single import           |
| `require('@plugin')`    | `@plugin '@plugin';`     | CSS-based plugin loading            |
| JavaScript theme config | `@theme { ... }`         | CSS variables in @theme block       |

## Step 6: Handle Edge Cases

### Custom Content Paths

```javascript
// ❌ Old (tailwind.config.js)
module.exports = {
  content: ["./src/**/*.{js,ts,jsx,tsx}", "./components/**/*.{js,ts,jsx,tsx}"],
}
```

```css
/* ✅ New (globals.css) */
@import "tailwindcss";

@source '../src';
@source '../components';
```

**Note:** Tailwind v4 auto-detects most file patterns. Only add `@source` if you have non-standard locations.

### Dark Mode Configuration

```javascript
// ❌ Old (tailwind.config.js)
module.exports = {
  darkMode: "class",
}
```

**✅ New:** Dark mode is automatic in v4. The `.dark` class works by default (no config needed).

```jsx
// Usage (unchanged)
<div className="bg-white dark:bg-gray-900">Automatic dark mode support</div>
```

### Container Queries

```javascript
// ❌ Old (tailwind.config.js)
module.exports = {
  plugins: [require("@tailwindcss/container-queries")],
}
```

```css
/* ✅ New (globals.css) */
@plugin '@tailwindcss/container-queries';
```

## Common Pitfalls & Solutions

### Issue 1: Styles Not Applying

**Problem:**

```bash
# Terminal shows:
warn - The `darkMode` option in your Tailwind CSS configuration is ignored
```

**Solution:**

- Delete `tailwind.config.js` completely
- Restart dev server
- v4 uses CSS config, not JS config

---

### Issue 2: Custom Colors Not Working

**Problem:**

```jsx
<div className="bg-brand-500">  {/* Not styled */}
```

**Solution:**
Check CSS variable naming:

```css
/* ❌ Wrong */
@theme {
  --brand-500: #3b82f6; /* Missing "color-" prefix */
}

/* ✅ Correct */
@theme {
  --color-brand-500: #3b82f6;
}
```

---

### Issue 3: Plugins Not Loading

**Problem:**

```
prose class has no effect
```

**Solution:**

```css
/* ❌ Wrong */
@import "@tailwindcss/typography"; /* Can't use @import */

/* ✅ Correct */
@plugin '@tailwindcss/typography'; /* Use @plugin directive */
```

---

### Issue 4: Content Detection

**Problem:**
Styles purged in production, classes missing.

**Solution:**
Tailwind v4 auto-detects most patterns. If you have non-standard file locations:

```css
@import "tailwindcss";

@source '../custom-dir';
@source '../another-dir';
```
