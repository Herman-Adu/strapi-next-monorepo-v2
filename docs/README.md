## 📝 Documentation Conventions

### File Naming

- **Index files:** `00-` prefix (e.g., `00-WELCOME.md`)
- **Sequential guides:** `01-`, `02-`, etc.
- **Uppercase names:** For main documentation
- **Kebab-case folders:** For directories

### Markdown Structure

```markdown
# Page Title

> **Last Updated:** Date  
> **Status:** Current status  
> **Related:** Links to related docs

## Section 1

Content...

## Section 2

Content...

---

## Next Steps

- Action item 1
- Action item 2
```

### Code Examples

- Use language-specific syntax highlighting
- Include file paths as comments
- Provide both "before" and "after" examples
- Show real-world use cases

### Cross-References

- Use relative paths for internal links
- Include context in link text
- Create a "See Also" section at the end
