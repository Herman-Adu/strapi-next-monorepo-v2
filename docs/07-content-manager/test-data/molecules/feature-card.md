## 💡 Usage Tips

- **Icon Choice**: Use emojis for informal sites, icon libraries (Lucide, Heroicons) for professional
- **Description Length**: 1-2 sentences max (150 characters ideal)
- **Call-to-Action**: Every card should have clear next step
- **Grid Layout**: 3 or 4 columns on desktop
- **Hover Effects**: Subtle lift/shadow on hover for interactivity

## 🎨 Card Variations

### Icon Top

```
Large icon (48px+)
Heading below icon
Description
CTA button at bottom
```

### Icon Left

```
Icon on left (smaller, 32px)
Heading + description on right
Inline layout
More compact
```

### Background Image

```
Background image or gradient
White text overlay
Icon + heading + description
Bold, visual style
```
