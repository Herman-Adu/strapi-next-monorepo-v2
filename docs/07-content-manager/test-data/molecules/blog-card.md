## 💡 Usage Tips

- **Image Quality**: Use high-quality featured images (1200x630px ideal)
- **Excerpt Length**: Keep to 2-3 sentences (150-200 characters)
- **Categories**: Limit to 3-5 main categories for easy filtering
- **Date Format**: Use consistent format (e.g., "March 15, 2024")
- **CTAs**: "Read More" or "Continue Reading" as link text

---

## 🎨 Card Layout Options

### Vertical Card

```
Image on top (full width)
Category badge overlay
Title
Excerpt
Author + Date + Read Time
```

### Horizontal Card

```
Image on left (40% width)
Content on right (60%)
More compact
Better for lists
```

### Minimal Card

```
Small thumbnail
Title (larger)
Category + Date only
Clean, scannable
```
