## 🖼️ Section Background Colors

These are special background styles used for section containers in Strapi:

### Theme Subtle Background (`theme-subtle-bg`)

**Light Mode:**

- Gradient from primary color at 3% opacity → 5% opacity
- **Default Theme**: Very subtle green tint (barely visible)
- **Adu Dev Theme**: Very subtle orange tint (barely visible)
- **Visual Effect**: Almost white with tiny hint of brand color

**Dark Mode:**

- Transparent (no background)
- **Visual Effect**: Inherits page background

**Usage:** Sections that need minimal visual separation without being obvious

---

### Theme Muted Background (`theme-muted-bg`)

**Light Mode:**

- Primary color at 10% opacity
- **Default Theme**: ![#16a34a1A](https://via.placeholder.com/100x30/e8f5eb/000000?text=Muted) Light green tint (calculated: `#e8f5eb`)
- **Adu Dev Theme**: ![#ff8c001A](https://via.placeholder.com/100x30/fff3e6/000000?text=Muted) Light orange tint (calculated: `#fff3e6`)
- **Visual Effect**: Noticeable but soft brand color wash

**Dark Mode:**

- Primary color at 5% opacity
- **Default Theme**: ![#22c55e0D](https://via.placeholder.com/100x30/0d1a11/ffffff?text=Muted) Very dark green tint (calculated: `#0d1a11`)
- **Adu Dev Theme**: ![#ffa5000D](https://via.placeholder.com/100x30/1a1508/ffffff?text=Muted) Very dark orange tint (calculated: `#1a1508`)
- **Visual Effect**: Subtle glow effect on dark background

**Usage:** Sections that need moderate visual emphasis, hero sections, CTAs

---

### Theme Pastel Background (`theme-pastel-bg`)

**Light Mode:**

- Flat color (no transparency)
- **Color**: ![#e8f5e9](https://via.placeholder.com/100x30/e8f5e9/000000?text=Pastel) `#e8f5e9` Mint green

## 🌈 Custom Gradient Color Picker Guide

### How to Choose Gradient Colors in Strapi

When setting up a **Custom Gradient** in Strapi, you'll see these fields:

#### Light Mode Gradient

```
lightModeStart   → First color (left/top)
lightModeMiddle  → Optional middle color (center)
lightModeEnd     → Last color (right/bottom)
```

#### Dark Mode Gradient

```
darkModeStart    → First color (left/top)
darkModeMiddle   → Optional middle color (center)
darkModeEnd      → Last color (right/bottom)
```

### Example: Newsletter Section Header

**Light Mode Gradient:**

- Start: `#FFA630` (Yellow-Orange) → End: `#00A7E1` (Blue)
- Creates a warm-to-cool transition

**Dark Mode Gradient:**

- Start: `#EEBD89` (Coral) → End: `#D13ABD` (Pink)
- Creates a peach-to-magenta glow

### Color Selection Tips

#### For Light Mode:

- **Start**: Use vibrant, saturated colors (they show well on white)
- **End**: Can be cooler or darker for contrast
- **Avoid**: Very light colors (#f0f0f0 range) - they disappear on white backgrounds

#### For Dark Mode:

- **Start**: Use bright, high-saturation colors (they pop on dark backgrounds)
- **End**: Can be subtle or vibrant depending on effect
- **Avoid**: Very dark colors (#1a1a1a range) - they disappear on dark backgrounds

## 🎯 Gradient Direction Reference

| Direction      | Effect                  | Best For                      |
| -------------- | ----------------------- | ----------------------------- |
| **Horizontal** | Left → Right            | Wide headings, banners        |
| **Vertical**   | Top → Bottom            | Tall text blocks, hero titles |
| **Diagonal**   | Bottom-left → Top-right | Dynamic, energetic feel       |
| **Radial**     | Center → Edges          | Spotlight effect, badges      |

## 💡 Quick Color Picker Tools

### Online Tools

- **Coolors.co**: Generate color palettes
- **Adobe Color**: Create harmonious gradients
- **ColorHunt.co**: Browse trending palettes

### How to Pick Complementary Colors

1. **Analogous** (next to each other on color wheel)

   - Example: Orange `#ff8c00` → Red-Orange `#ff6347`
   - Creates smooth, harmonious gradients

2. **Complementary** (opposite on color wheel)

   - Example: Blue `#00a7e1` → Orange `#ffa630`
   - Creates vibrant, high-contrast gradients

3. **Triadic** (evenly spaced on color wheel)
   - Example: Green `#22c55e` → Purple `#8b5cf6` → Orange `#ff8c00`
   - Creates balanced, colorful gradients

## 🔍 How to Test Your Colors

### In Strapi:

1. Go to **Content Manager** → Your page
2. Edit the section with TextStyle
3. Set **textStyle** to `gradient`
4. Set **gradientDirection** (horizontal/vertical/diagonal/radial)
5. Add **customGradient** component
6. Fill in **lightModeStart** and **lightModeEnd** (required)
7. Optionally add **lightModeMiddle** for 3-color gradient
8. Repeat for **darkMode** colors
9. **Save & Publish**

### On Frontend:

1. Refresh the page in **light mode**
2. Check gradient looks good
3. Toggle to **dark mode** (sun/moon icon in header)
4. Verify dark gradient shows correctly
5. Test on different screen sizes

## 🎨 Color Accessibility Guidelines

### Contrast Ratios (WCAG AA)

- **Normal text**: At least 4.5:1
- **Large text** (18pt+): At least 3:1
- **UI elements**: At least 3:1

### Tools to Check Contrast:

- **WebAIM Contrast Checker**: webaim.org/resources/contrastchecker
- **Coolors Contrast Checker**: coolors.co/contrast-checker

### Gradient Text Accessibility:

- Ensure at least one color in gradient has good contrast with background
- Test readability in both light and dark modes
- For critical text (headings), use high-contrast colors

## 📞 Need Help?

- Use the color tables above to identify current theme colors
- Reference gradient examples for inspiration
- Test colors on both light and dark modes before publishing

**For Designers:**

- All theme variables are in `apps/ui/src/styles/globals.css`

- Dark mode automatically switches using CSS custom properties

**For Developers:**

- See `COMPONENT_INTEGRATION_GUIDE.md` for technical implementation
- Color variables use CSS custom properties for theming
- Gradients use inline styles with CSS variable fallbacks for dark mode
